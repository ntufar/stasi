Stasi Support

Stasi shows live Athens bus arrivals from the OASA Telematics API.

Contact

To ask a question or request support, open a new issue on GitHub: github.com/ntufar/stasi/issues.

Before you open an issue, include these details:

  • The app version and build number (Settings).
  • Your device model and iOS or Android version.
  • The steps that cause the problem.

Live data and demo data

The OASA API answers only on some networks. Outside Greece, it can be unreachable. When this happens, the app shows a banner and bundled demo data for two sample lines. Tap Try live data on the banner, or turn off Use demo data in Settings, to retry live data.
